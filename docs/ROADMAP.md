# Takto roadmap

## 0.1.x — stabilizacija temelja

- puni GitHub CI build i rješavanje svih Android lint/build grešaka
- regresijski testovi spremanja i migracije podataka
- dodatno poliranje kalendara na malim i velikim Android ekranima
- testiranje obavijesti na Android 13+
- provjera backup/restore kompatibilnosti

## 0.2.x — kvaliteta rasporeda

- naprednije uređivanje radnog vremena
- bolji pregled mjesečnog fonda i odstupanja
- dodatni filtri statistike
- poboljšan rad s velikim brojem vlastitih oznaka i uzoraka

## Kasnije

- lokalizacije nakon stabilizacije hrvatskog sučelja
- dodatni formati izvoza samo ako imaju jasan praktični razlog
- release automatizacija nakon što CI i potpisivanje budu stabilni
